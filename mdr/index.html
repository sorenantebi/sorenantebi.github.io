FILE 00 · PROJECT BRIEF

            
BRAIN TUMOUR SEGMENTATION · U-NET IN C++

          

          
        

        

        

          

            
ABSTRACT

            
I implemented a U-Net from scratch in C++ with LibTorch, the PyTorch C++ API, and trained it to segment brain tumours in 2D MRI slices from BraTS (Medical Segmentation Decathlon, Task 01).

            
Every pixel is labelled background, edema, non-enhancing tumour or enhancing tumour.

            
The trained weights were exported and the forward pass rewritten in plain JavaScript, so the model you are about to use runs entirely on this terminal.

          

          

            
DATA
2,028 train / 730 test slices from 338 / 146 patients · 120×120

            
MODEL
4-level U-Net · 16→128 filters · skip connections · 481,796 params

            
TRAINING
Cross-entropy · Adam 1e-3 · batch 4 · 10 epochs · Apple GPU (MPS)

            
TEST DICE
Whole tumour 0.67 · edema 0.49 · non-enh. 0.46 · enhancing 0.71

          

        

        
PREDICTIONS ARE FOR REFINEMENT, NOT DIAGNOSIS
