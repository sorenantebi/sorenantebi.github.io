    Projects · 05
    
    
    C++ · LibTorch · BraTS
    
    
    Brain tumour segmentation with a U-Net in C++
    
    
    A U-Net written from scratch with LibTorch, the PyTorch C++ API, trained to label every pixel of a 2D brain MRI slice as background, edema, non-enhancing tumour or enhancing tumour. The data comes from BraTS (Medical Segmentation Decathlon, Task 01).
    
    
    Architecture
    
    
    How it works
      
      
    • Encoder: four levels of two 3×3 convolutions with BatchNorm and ReLU. Instead of max-pooling, the first convolution of each level has stride 2, halving the resolution (120 → 60 → 30 → 15) while channels double (16 → 128).
      • 
      
    • Decoder: 2×2 transposed convolutions upsample back to 120×120. At each level the upsampled map is concatenated with the encoder map of the same size, so fine detail lost in downsampling comes back. A final 1×1 convolution produces 4 class scores per pixel, and the argmax gives the mask.
      • 
      
    • Data: a custom LibTorch dataset loads the PNG slices with stb_image, scales them to [0, 1] and pads both image and label to a multiple of 8 so the three stride-2 steps divide evenly.
      • 
      
    • Training: cross-entropy loss, Adam at 1e-3, batch size 4, 10 epochs on the Apple GPU (MPS), falling back to CUDA or CPU. The checkpoint with the lowest validation loss is kept.
      • 
    
    
    
    Encoder level · encoder.cpp
    // encoder.cpp — each level halves the resolution with a stride-2 conv, doubles the channels
n = n*2; // 32
enc2 = torch::nn::Sequential(
    torch::nn::Conv2d(torch::nn::Conv2dOptions((int64_t)(n/2), n, 3).stride(2).padding(1)), // 60x60
    torch::nn::BatchNorm2d(n),
    torch::nn::ReLU(),
    torch::nn::Conv2d(torch::nn::Conv2dOptions(n, n, 3).padding(1)),
    torch::nn::BatchNorm2d(n),
    torch::nn::ReLU()
);
    
    
    Decoder forward pass · decoder.cpp
    // decoder.cpp — upsample, concatenate the matching encoder map, convolve
torch::Tensor Decoder::forward(std::vector<torch::Tensor> connections){
    auto b1 = b->forward(connections[3]);
    auto y1 = dec1->forward(torch::cat({b1, connections[2]}, 1));
    auto t1 = dec1_t->forward(y1);
    auto y2 = dec2->forward(torch::cat({t1, connections[1]}, 1));
    auto t2 = dec2_t->forward(y2);
    auto y3 = dec3->forward(torch::cat({t2, connections[0]}, 1));
    return y3;   // [batch, 4, H, W] logits
}

    Projects · 01
    
    
    Paper · Deep learning feature matching · IEEE IJCNN 2026 (accepted)
    
    
    Hybrid Deep Learning for Traceability and Classification of Industrial Slate Tiles
    
    
    One lightweight model that does two jobs on natural slate: it re-identifies the same tile across camera views, and it classifies which of six Spanish quarries the tile came from. XFeat's fine-grained local features handle matching and add surface texture to classification. MobileNetV3 supplies global semantics.
    
    
    Architecture
    
    
    
      
      
    How it works
      
        
    • XFeat (frozen) outputs a keypoint heatmap K and a 64-d dense descriptor map F at 1/8 resolution, fusing features from 1/8, 1/16 and 1/32 scales.
      • 
        
    • Matching: keypoints and descriptors from both views go into a slimmed-down LightGlue (6 layers, 1 attention head instead of 9 and 4), which alternates self- and cross-attention and stops early once it is confident.
      • 
        
    • Classification: F and MobileNetV3-small's 576-d embedding are average pooled, each projected to d dimensions (Linear, LayerNorm, HardSwish), concatenated, and passed through a two-layer fusion block with dropout to 6 classes. Only the heads are trained.
      • 
        
    • Data: tiles segmented with SAM2 from two-point prompts, cropped onto black, then randomly cropped to 720×720 so the model learns surface texture rather than cut edges.
      • 
      
    
    
    
    
    Against a human expert
      
      
    • Compared with a slate specialist with 30+ years of experience, classifying from images alone.
      • 
      
    • On the two quarries that are hardest to tell apart, the model scored 87.5% recall versus 53.8% (SIN 320) and 38.4% (SIN 360) for the expert. It matched the expert on the distinctive classes.
      • 
      
    • Training: AdamW at 1e-3, batch size 16, 100 epochs, 5-fold cross-validation. Evaluated on a desktop CPU and a Raspberry Pi 5 for edge deployment.

    Projects · 02
    
    
    MSc thesis · Adversarial deep learning for bias mitigation
    
    
    Bias Analysis in Chest X-ray Disease Detection Models
    
    
    Pre-trained "foundation" models are attractive in medical imaging, where datasets are small and imbalanced. But deep classifiers can detect protected attributes such as sex and race from X-rays, and might use them as shortcuts. This thesis probes TorchXRayVision models for that kind of bias, then tests Domain Adversarial Neural Networks (DANNs) as a fix when labels are corrupted for one subgroup.
    
    
    
      
    DANN architecture
    
        
    
      
    
    
    
    
      
      
    How it works
      
        
    • Bias analysis: retrain classification heads on CheXpert over frozen and unfrozen XRV and ImageNet backbones. Compare subgroup ROC curves and Youden's J, and project penultimate features with PCA and t-SNE, testing marginal shifts between subgroups with Kolmogorov–Smirnov.
      • 
        
    • Label corruption: simulate underdiagnosis by flipping positive findings to "No Finding" for one subgroup (systematic noise), or assign random labels to it (random noise).
      • 
        
    • DANN: one shared backbone, three linear heads. Disease loss trains its head and the backbone. Race and sex heads train on frozen features. Once the race head is reliable, its signal is turned against the backbone so the features stop encoding race.
      • 
        
    • Two adversaries: gradient negation multiplies the race loss by −ω before it reaches the backbone. Confusion loss instead pushes race predictions towards uniform. ω fades in logistically, so the adversary only acts after 20k steps.
      • 
      
    
    
    
    
    Findings
      
      
    • Frozen backbones consistently performed worse and showed spurious links between disease predictions and protected attributes.
      • 
      
    • Unfrozen XRV models showed no strong evidence of using sex or race to predict disease, though higher PCA modes carried some subgroup disparities.
      • 
      
    • DANNs nearly restored ROC curves distorted by label noise and removed subgroup shifts in feature space, at the cost of a lower Youden's J than baseline.
      • 
      
    • Gradient negation targeted the race head precisely. Confusion loss also disturbed sex classification, suggesting it reshapes the backbone more broadly.
      •
